# 簽帳單管理與帳務核對系統

企業級月底會計簽帳單管理、繳交收件、缺單追蹤、帳務自動核對與月結報表系統。

嚴守「**簽帳單可追蹤、責任可查詢、缺單能預警、帳務可核對**」與「**已繳交不等於已收件**」雙重驗收機制。

---

## 🚀 GitHub Pages 自動部署設定步驟

本專案已配置好完整的 GitHub Actions 自動化部署工作流程（`.github/workflows/deploy.yml`）與 Vite 相對路徑設定（`base: './'`），只要開啟 GitHub 倉庫設定即可自動發布！

### 步驟 1：在 GitHub 設定頁開啟 GitHub Actions 來源
1. 前往您的 GitHub 專案倉庫頁面。
2. 點擊頂部的 **「Settings」**（設定）標籤頁。
3. 在左側側邊欄中點選 **「Pages」**。
4. 在 **「Build and deployment」** 區塊：
   * **Source** 下拉選單請選擇：**`GitHub Actions`**（預設為 Deploy from a branch，請務必切換為 GitHub Actions）。

### 步驟 2：觸發部署
* 當您將程式碼推送到 `main` 或 `master` 分支時，GitHub Actions 會自動觸發建置與部署。
* 您也可以至專案倉庫的 **「Actions」** 分頁，選擇 **「Deploy to GitHub Pages」**，並點擊右側的 **「Run workflow」** 手動觸發。

### 步驟 3：瀏覽您的網站
部署完成後（約 1~2 分鐘），您即可在：
`https://<您的GitHub帳號>.github.io/<倉庫名稱>/`
正常呈現並操作完整的簽帳單管理系統！

## 🛠️ 本地開發與建置

```bash
# 安裝依賴
npm install

# 啟動本機開發伺服器
npm run dev

# 建置正式生產版本 (輸出至 dist 目錄)
npm run build

# 本地預覽建置成果
npm run preview
```

## 📋 系統功能模組

* **F01｜簽帳單資料管理**：新增簽帳單、唯一單號防重複、CSV/Excel 批次匯入與範本下載。
* **F02｜簽帳單繳交與收件**：外勤登記繳交、會計點收確認、退回更正與交接時程追蹤。
* **F03｜簽帳單查詢**：多條件複合篩選、關鍵字檢索、篩選結果 CSV 匯出。
* **F04｜帳務核對**：ERP 銷貨帳目與實體簽單兩方自動比對、金額不符異常標示、人工調解與月結結案。
* **F05｜缺單追蹤與提醒**：自動彙整逾期缺單、T+3 期限警示、一鍵複製 LINE 催單文案、催單歷程記錄、主管特案異常結案。
* **F06｜管理與月結報表**：月結完成率、外勤人員繳交績效表、逾期排行榜、月結報表匯出。
* **第四階段進階自動化**：條碼 / QR Code 掃描快速收件點收模擬器、規格書第八章（AT-01 ~ AT-10）驗收測試互動演練器。
